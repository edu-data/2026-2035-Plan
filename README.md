# 경인교육대학교 중장기 발전계획(안) (2026-2035)

## IPA 분석 대시보드

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://edu-data.github.io/2026-2035-Plan/ipa_dashboard.html)

경인교육대학교 중장기 발전계획(안)(2026-2035) 수립을 위한 **중요도-수행도 분석(IPA: Importance-Performance Analysis)** 대시보드입니다.

## 📊 주요 기능

### 그룹별 분석

- 👥 **종합(전체)**: 모든 응답자 통합 분석
- 👨‍🏫 **교직원**: 교직원 그룹 분석
- 🎓 **졸업생**: 졸업생 그룹 분석  
- 📚 **학부생**: 학부생 그룹 분석

### 분석 유형 (4개 탭)

| 탭 | 분석 내용 |
|------|------|
| 📊 **종합** | 9개 영역 IPA (핵심가치, 위기요인, 대응방향, 5대전략, I~V 전략) |
| 📋 **세부영역별** | 핵심가치(5), 위기요인(5), 대응방향(5), 5대전략(5) 개별 IPA |
| 🎯 **5대 발전전략** | I~V 전략 비교 분석 + 바 차트 |
| 📝 **21개 세부과제** | 전체 과제 IPA + 갭 순위 테이블 |

### IPA 4분면 해석

| 분면 | 의미 | 전략적 방향 |
|------|------|------|
| 🔴 **I. 집중개선** | 중요도 ↑ 수행도 ↓ | 우선적으로 개선 필요 |
| 🟢 **II. 유지강화** | 중요도 ↑ 수행도 ↑ | 현 수준 유지 및 강화 |
| ⚪ **III. 저우선** | 중요도 ↓ 수행도 ↓ | 점진적 개선 검토 |
| 🔵 **IV. 과잉투자** | 중요도 ↓ 수행도 ↑ | 자원 재배치 고려 |

## 📊 분석 대상

### 세부 영역

- **핵심가치**: 혁신, 창의, 수월, 배려, 소통
- **위기요인**: 시대적 변화 대응, 저출산, 교육적 배려, 교육대학원, 교육청 협력
- **대응방향**: 특수목적 실현, 교사교육기관, 시대적 변화 대응, 교육 기회균등, 지역사회 연계

### 5대 발전전략

1. **I. AI·스마트 캠퍼스 혁신** (4개 과제)
2. **II. 교육연구 선도** (4개 과제)
3. **III. 포용성·공공성 고도화** (4개 과제)
4. **IV. 학생역량·행복 증진** (4개 과제)
5. **V. 글로벌 허브** (5개 과제)
